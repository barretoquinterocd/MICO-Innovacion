# MICO Innovación — V1.12 GitHub Pages

Herramienta web estática orientadora para valorar, proteger, conectar, transferir e internacionalizar conocimiento científico, tecnológico y creativo.

## Uso público en GitHub Pages

Suba estos archivos directamente en la raíz del repositorio:

- `index.html`
- `README.md`
- `logo_ceap.png`
- `logo_faces_ucv.png`
- `logo_legin.png`
- `logo_ucv.png`
- `mico_isotipo.png`

Luego active GitHub Pages desde **Settings → Pages → Deploy from a branch → main → /root → Save**.

## Ajuste visual acordado

- Los logotipos institucionales aparecen centrados en el encabezado.
- No aparece el título grande debajo del encabezado.
- No aparece la frase “Micelio Inteligencista para la Comercialización del Conocimiento” debajo del logotipo lateral.
- La frase orientadora queda como banda breve bajo los logotipos.
- El panel de trabajo y los entregables quedan apilados en horizontal completo para evitar columnas innecesarias.

## Nota técnica

El mapa coroplético y el radar IFEC usan Plotly desde CDN. Si no hay conexión a Internet, la herramienta conserva funciones locales de respaldo para evitar cuadros vacíos.
